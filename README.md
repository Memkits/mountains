# 吉隆口岸 WebGPU 3D 地形

一个仅面向桌面版 Google Chrome 的三维地形浏览器。项目以吉隆口岸（`28.27972° N, 85.37778° E`）为中心，通过 Three.js WebGPU 渲染约 `50 × 50 km` 的真实高程地形。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。浏览器需要支持 WebGPU，并开启硬件加速。

## 控制

- 鼠标拖拽：环视；滚轮：缩放。
- `W / A / S / D`：水平移动；`Q / E`：降低 / 升高视点。
- 手柄左摇杆：平移；右摇杆：环视；`LT / RT`：升降；`LB / RB`：加速。

手柄输入参考了 `protea` 的相机控制方式，包含死区和非线性摇杆响应。

## 数据与性能

- DEM：Mapzen Terrain Tiles on AWS，Terrarium RGB 编码；当前区域的元数据标记为 SRTM `N28E085` 数据源。
- 只加载中心周围 `3 × 3` 个瓦片，最多 3 个并发请求。
- 高精细模式约 29.5 万个三角形；平衡模式约 7.4 万个三角形。
- 瓦片解码结果在页面会话内缓存，切换细节级别不会重复下载。
- 渲染像素比上限为 `1.75`，避免高 DPI 显示器过度消耗 GPU。
